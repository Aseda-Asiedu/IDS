Understanding Streaming Concept Drift in Network Security

Traditional static machine learning intrusion detection models assume stationarity — that network traffic distributions today will mirror the training dataset forever. In live university and campus networks, this assumption quickly fails due to legitimate shifts (software updates, semester exams, new video streaming platforms) and evolving zero-day adversary techniques.

Adaptive Windowing (ADWIN)

ADWIN automatically expands its sliding window when the stream is stationary to minimize variance, and rapidly contracts the window when statistically significant differences between sub-windows appear.

Hoeffding Tree Adaptation

Upon ADWIN detecting drift, the Adaptive Random Forest drops underperforming background tree branches and initiates new candidate split evaluations without discarding the entire model.

False Alarm Suppression

By continually adapting to non-hostile distribution shifts, NEXz prevents alert fatigue and keeps security operators focused on genuine zero-day behavioral anomalies.

Contextual Protocol Academy

RFC protocol standards linked to real packet structures (Learn → Observe → Security → Explore)

Select Attack Archetype:

1. Port Scan Reconnaissance

Probing sequential or random destination ports to discover running network services

Reconnaissance
What Happened?

A remote or internal host sent rapid TCP SYN packets to multiple different destination ports within a short observation window without completing the full TCP three-way handshake.

Why Does It Matter?

Reconnaissance is the initial phase of cyberattacks (MITRE ATT&CK T1046). Adversaries identify exposed listening services (e.g. SSH on port 22, RDP on port 3389) before launching targeted exploits.

What Did NEXz Observe?
Telemetry Signatures: Flow duration < 0.1s, packet size < 64 bytes, TCP SYN flag set without ACK, target port dispersion across destination IPs.
Analyst & Student Investigation Playbook
  1. Navigate to Monitor → Traffic Analysis and check the Top Targeted Destination Ports widget.
  2. Filter Monitor → Flows by the suspicious source IP and verify TCP handshake flags (SYN-SENT vs ESTABLISHED).
  3. Determine whether the scanner is an authorized campus administrative tool (e.g. vulnerability scanner) or an unauthorized intruder.
  4. If unauthorized, acknowledge the alert in Security → Alerts and configure a perimeter firewall block on the border router.
